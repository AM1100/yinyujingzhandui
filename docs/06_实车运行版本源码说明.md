# 实车运行版本源码说明

记录日期：2026-10-18。来源：队伍提供的源码检索包 01 目录及队伍本次确认。

## 1. 四轮底盘与机械臂控制

队伍确认使用 xproject 工程下载后，小车能够运行。本次未现场测试，也未回读实板固件核对哈希。

完整源码见根目录 [CRTC_xproject_实车运行源码.zip](../CRTC_xproject_实车运行源码.zip)，解压后打开 `xproject_runtime/Project/xproject.uvprojx`，保留目录结构。包内按原样保留 C、头文件、启动汇编、工程配置和原始说明，未包含旧编译产物，也未包含相对路径失效的顶层重复工程文件。34 项工程文件引用已检查存在，本次未实际编译。

`Robot/main.c` 包含 PS2 读取、四轮混控、GPIO 电机方向输出、TIM4 四路舵机 PWM，以及 SELECT 驾驶/机械臂模式切换。底盘不是 PWM 比例调速版本；GPIO 电机控制与舵机 PWM 不应混淆。舵机、抓取与携物的实际完成情况不能由小车能跑这一反馈推出。

## 2. 版本与验证边界

工程目标为 STM32F103RC，实板型号仍待丝印确认。02 C8T6 低速 v1.1 和 03 RC 低速 v1.0 不在此源码包内，仍作为待实车验证的开发版本。

中文注释部分已在收到时损坏为问号，本次没有猜测补写。无线断开后接收器是否重复旧帧、异常保护有效性、方向切换响应均未在本次测试。代码存在不等于各考核指标已通过。

底层 ax_* 驱动与配套例程来自 XTARK（塔克创新）PS2 手柄例程；芯片标准外设库及 CMSIS 来源见各文件原始声明。保留原始版权头与 Doc/ax_readme.txt，不替第三方代码重新声明许可。当前收到的 XTARK 文件含版权声明，尚未核实具体再分发许可，不能仅因可以取得代码就称其为已确认开源。队伍应补充实际获得授权的依据及所用版本。

机械模型来源与待核许可见机械臂日志末章；本源码包没有加入模型文件。
