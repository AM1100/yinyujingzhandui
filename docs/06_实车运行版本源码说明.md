# 实车运行版本源码说明

记录日期：2026-10-18。来源：队伍提供的源码检索包 01 目录及队伍本次确认。

## 1. 四轮底盘与机械臂控制

队伍确认使用 xproject 工程下载后，小车能够运行。本次未现场测试，也未回读实板固件核对哈希。

控制主程序与工程配置见根目录 [CRTC_xproject_实车运行源码.zip](../CRTC_xproject_实车运行源码.zip)。2026-10-18 许可核查后，公开包仅保留 `Robot/main.c`、`Project/xproject.uvprojx` 和依赖恢复说明；不再附带尚未确认再分发权限的驱动、库和启动文件。名称沿用旧链接，但它已不是完整可编译工程。完整原始工程由队伍本地保管；本次没有修改实车控制代码。

此前在完整本地工程中检查的 34 项引用均存在；这项结论只适用于队伍本地完整工程，不适用于当前精简公开包。本次未实际编译。

`Robot/main.c` 包含 PS2 读取、四轮混控、GPIO 电机方向输出、TIM4 四路舵机 PWM，以及 SELECT 驾驶/机械臂模式切换。底盘不是 PWM 比例调速版本；GPIO 电机控制与舵机 PWM 不应混淆。舵机、抓取与携物的实际完成情况不能由小车能跑这一反馈推出。

## 2. 版本与验证边界

工程目标为 STM32F103RC，实板型号仍待丝印确认。02 C8T6 低速 v1.1 和 03 RC 低速 v1.0 不在此源码包内，仍作为待实车验证的开发版本。

中文注释部分已在收到时损坏为问号，本次没有猜测补写。无线断开后接收器是否重复旧帧、异常保护有效性、方向切换响应均未在本次测试。代码存在不等于各考核指标已通过。
