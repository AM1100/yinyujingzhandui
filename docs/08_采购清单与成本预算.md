## 3. 合计核算与未计费用

18项小计之和为 **353.48元**，与官方表总计一致；有数量、单价的17项均已检查“数量×单价=小计”。

18650电池一行在原表中没有填写数量与单价，小计标为0.00元。此处如实转录，表示官方合计没有计入实际电池费用，不代表电池免费，也不推定本队未购买。实际电池金额与数量待补，因此353.48元不能称为包含全部电池费用的最终实付总额。3D打印、紧固件、胶粘剂、运费及其他未列项目，也没有额外估价计入。

无线继电器按队伍“全表采购”的确认保留为2套、27.60元；手册附录说明通过中期前无需购买，不改变本次用户确认的采购范围。

## 4. 核心选型与设计对应

- STM32核心板与PS2手柄：用于主控和遥控输入。采购表型号为C8T6，而历史xproject配置为F103RC；采购记录不自动证明实际装车芯片型号，仍保留实板丝印核对事项。
- 8个TT马达、2套麦轮和2块底盘：数量用于两台四轮底盘的采购规划；安装、轮序与实际运动效果依各台实物演示核验。
- MG995与SG90：用于机械臂关节及夹爪的选型，具体安装位置与实际舵机型号按装配记录核对，不由采购表反推承载能力。
- DRV8833、电池盒及降压模块：用于电机执行和供电系统，供电与接线仍须按实际模块及器件规格核对。
